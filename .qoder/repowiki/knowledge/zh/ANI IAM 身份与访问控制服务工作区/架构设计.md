根模块 `github.com/zhangzhe-ctrl/ani-iam` 通过 go.mod 将 api_proto、server_entrypoint、internal_core、sdk、examples、tests、tools、deploy、docs 等子模块统一纳入同一依赖图：api_proto 由 buf/protoc 生成后供 internal_core 的 server 层与 sdk 共同消费；server_entrypoint 作为唯一可执行入口，按 configs/config.yaml 中的 profile（如 workload-isolated）加载 Kratos 应用并装配 biz→data→service→server 分层；migrations 提供 PostgreSQL DDL，由独立的 ani_iam_migrator 在隔离环境中执行；sdk 暴露 mTLS + 工作负载身份校验的 gRPC 客户端，被 examples 与外部消费者引用；tests 使用 testcontainers 拉起 Postgres/Redis/Dex/NATS 完成契约校验、CP0 生命周期与全链路集成验证；deploy 输出 CF-01 割接演练的 current/target 双环境 K8s 清单；tools 为 WR17-20 重构工作区提供远程执行与快照校验。所有子模块共享同一份 iam/v1 gRPC 契约、OIDC/Dex 配置与 policy revision 哈希，确保契约、运行时与部署三者一致。
