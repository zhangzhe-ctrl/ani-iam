- 用例以 `*Usecase` 结构体组织，并通过 `NewXxxUsecase(...)` 构造函数注入所有依赖，可选的平台用例通过 `WithPlatformXxx` 方法延迟注入。
- 所有写操作通过 `TenantUnitOfWork.WithinTenant` 或专用 UoW 接口在事务边界内执行，并将领域变更与 `SecurityAuditEvent` 一起持久化。
- 领域错误统一以包级 `var ErrXxx = errors.New(...)` 声明，并在自定义错误类型上实现 `Unwrap()` 以便 `errors.Is` 匹配。
- 时间来源一律通过注入的 `Clock.Now().UTC()` 获取，禁止直接调用 `time.Now()`，便于测试与可重现性。
- ID 生成统一委托给 `IDGenerator`，并在校验处要求返回 UUIDv7，否则返回 `ErrInvalidGeneratedID`。
- 跨用例共享的领域状态（Principal/Membership/Session/Grant/Lifecycle 等）使用 string 类型枚举常量集中声明，避免散落的魔法字符串。
- 需要租户隔离的操作一律以 `TenantScope` 作为第一个参数传入，scope 内部持有私有 tenantID，只能通过 `NewTenantScope` 构造，防止越权。
- 所有鉴权失败路径统一通过 `recordAuthorizationAuthenticationFailure` / `deny` / `denyUnbound` 记录审计事件并返回带 `AuthorizationReason` 的决策结果。
