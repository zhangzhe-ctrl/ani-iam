本包为 CP0-0 级别的纯 Go 领域层，不依赖任何传输或持久化框架，仅通过接口抽象外部能力：
- 用例入口：每个文件对应一个用例聚合（`authentication.go` 密码登录/刷新/登出/切换租户；`authorization.go` 基于策略注册表的权限检查；`session.go` 会话续期与注销；`workload.go` 工作负载身份与直连调用者；`membership.go` 租户成员创建；`idempotency.go` 通用幂等执行器；`oidc.go`、`password_action*.go`、`principal_validation.go`、`tenant_*.go`、`workload_bootstrap/caller/invocation.go`）。所有用例以 `*Usecase` 结构体暴露，通过构造函数注入依赖。
- 依赖方向单向向外：用例只消费接口（如 `AuthenticationReader`、`AuthorizationPolicyRegistry`、`AccessCredentialVerifier`、`TenantUnitOfWork`、`IDGenerator`、`Clock`、`SecretGenerator`），由上层 composition root 装配具体实现。
- 边界类型集中定义：`TenantScope`（私有 tenantID 字段 + `NewTenantScope` 构造）、`Principal/Membership/TenantAccess/Lifecycle/Session/Grant` 状态枚举、`AuditAction/AuditTargetType/AuditReason/AuditBoundary/AuditSourceService` 审计常量、`AccessTokenClaims`、`TrustedPrincipalContext`、`DirectCaller` 等跨用例共享的领域对象。
- 事务与审计内聚：每个写用例通过 `TenantUnitOfWork.WithinTenant` 或专用 UoW（如 `LoginUnitOfWork`、`SessionContinuityUnitOfWork`）将领域实体与 `SecurityAuditEvent` 原子写入，失败时回滚。
- 平台扩展点：`PlatformPasswordUsecase`、`PlatformSessionUsecase`、`PlatformAuthorizationUsecase` 通过可选的 `WithPlatformXxx` 注入，使 BOSS/Console 等不同 audience 走不同分支但保持同一用例入口。
- 策略驱动：`authorization.go` 通过 `AuthorizationPolicyRegistry` 按 operationID 查找策略，校验 credential/principal kind 白名单后再委派到 repository 查询真实权限。
