- 所有对外构造器（NewGRPCServer、NewTargetGRPCServer、NewAdminServer、NewObservability、NewWorkloadIdentityMiddleware、LoadMutualTLSServerConfig）采用显式参数注入并在入参为空或非法时返回错误，而非使用全局配置。
- gRPC 错误统一通过 `status.New(...).WithDetails(&errdetails.ErrorInfo{...})` 附加 Reason、Domain 与 operation_id/decision_id 元数据后再 `.Err()` 返回。
- 可观测性指标通过 `Int64ObservableGauge` + 回调读取 `atomic.Int64` 字段的方式暴露运行时状态（如 readiness、API key 快照等）。
- 中间件链由 `Observability.ServerMiddleware` 集中声明，顺序固定为 recovery → metadata → tracing → logging → metrics → validate，业务中间件在其后追加。
- 跨进程通信的身份信息通过 `biz.WithDirectCaller` 注入 context，由下游 biz 层消费，避免在服务层直接持有调用者对象。
