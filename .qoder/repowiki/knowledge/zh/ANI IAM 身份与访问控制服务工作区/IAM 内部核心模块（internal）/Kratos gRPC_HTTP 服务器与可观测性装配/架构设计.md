模块以 `server.go` 为包入口，按职责拆分为多个文件：`grpc.go` 通过 `NewGRPCServer` 构造带强制 mTLS（TLS1.3 + 客户端证书）的 Kratos gRPC Server，并由 `NewTargetGRPCServer` 注册 Authentication/Authorization/IAMAdmin 三个 IAM v1 服务；`admin.go` 用 `kratoshttp.Server` 暴露 `/healthz`、`/readyz`、`/metrics` 三个管理端点，其中 `/readyz` 依赖 `Readiness` 状态；`tls.go` 提供 `LoadMutualTLSServerConfig`，从配置加载服务端证书与 Client CA 并强制最小 TLS 版本与双向认证；`workload_identity.go` 实现基于 x509 DNS SAN 的工作负载身份中间件，在 gRPC 链中验证证书链、调用 `biz.WorkloadAuthentication`/`WorkloadAuthorization` 完成鉴权并将调用者注入上下文；`observability.go` 构建 `Observability`，统一初始化 Prometheus Registry、OpenTelemetry MeterProvider/TracerProvider，并通过 `ServerMiddleware` 返回 recovery→metadata→tracing→logging→metrics→validate 的标准中间件链；`readiness.go` 提供可插拔的依赖就绪探针（周期性执行 check 函数），被 admin 端点和 observability 指标共同消费。依赖方向单向向外：仅依赖 `internal/conf`、`internal/biz` 及第三方库，不反向引用业务实现。
