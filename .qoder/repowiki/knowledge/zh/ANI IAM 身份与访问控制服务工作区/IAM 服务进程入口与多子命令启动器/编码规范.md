- 子命令通过检查 `os.Args[1]` 在 `main` 中早期分支分发，每个分支调用对应的 `runXxx` 函数并以非零退出码打印错误后 `os.Exit(1)`。
- 后台定时任务统一实现 `Start(context.Context) error` / `Stop(context.Context) error` 接口，内部以 `context.WithCancel` + `sync.Mutex` 保护 `started` 状态，并通过 `done chan struct{}` 等待 goroutine 结束。
- 运行时依赖（PostgreSQL、Redis、OIDC、gRPC 客户端等）在 `buildApp` 中集中构造并显式 Ping/Validate，失败时通过 `closeRuntime` 闭链释放已分配资源。
- 对外部资源的关闭通过 `AfterStop` 钩子按依赖逆序注册（notification → runtime → observability），确保优雅停机。
- 一次性 CLI（如 workload provisioner）对输入文件实施严格白名单校验：限制文件大小、校验私钥文件权限位、比对 SHA-256、拒绝未知 JSON 字段，并将错误归一化为 `biz.ErrWorkloadBootstrap*` 语义化错误。
- 日志 handler 通过 `log.FilterKey` 显式过滤敏感键（password、token、dsn、private_key 等），并在 slog 顶层附加 `service.id/name/version` 固定标签。
