- 所有主键 ID 使用 uuid v7，并通过 `CHECK (substring(id::text FROM 15 FOR 1) = '7')` 强制校验。
- 租户相关表统一包含 `version bigint NOT NULL CHECK (version > 0)`、`created_at`/`updated_at` 时间戳以及 `CONSTRAINT *_nonzero_tenant CHECK (tenant_id <> '0000...0'::uuid)` 非零租户约束。
- 外键一律使用 `ON DELETE RESTRICT`，跨表关联采用 `DEFERRABLE INITIALLY DEFERRED` 延迟约束以避免循环依赖。
- 枚举字段通过 `CHECK (column IN (...))` 限制取值范围，禁止使用数据库序列或外部字典。
- 对敏感表（如 iam_audit_events、principals）通过末尾的 `GRANT SELECT[, INSERT] ... TO ani_iam_runtime` 精确授予最小权限，而非赋予角色。
- 迁移文件顶部用注释标注 DP/WR 编号及变更意图，并在必要时调用 `UPDATE iam_schema_revision SET revision = '<id>' WHERE singleton` 记录版本。
