- 所有 `.proto` 文件统一声明 `package iam.v1` 与 `option go_package = "github.com/zhangzhe-ctrl/ani-iam/api/iam/v1;iamv1"`，使生成的 Go 包名一致。
- 共享枚举与基础消息集中放在 `contract.proto`，服务 proto 通过 `import "contract.proto"` 引用，避免重复定义。
- 错误处理统一采用 `google.rpc.ErrorInfo` 并通过 `IAMErrorDetails` 包装，配合 `IAMErrorReason` 枚举表达稳定错误原因。
- 请求体普遍包含 `idempotency_key` 字段，响应中通过 `MutationResult` 返回资源 version 以支持幂等写入。
- 边界隔离通过 `Boundary` oneof（TenantBoundary / PlatformBoundary）表达，禁止使用空字符串或魔法值表示平台边界。
- 工作负载相关消息（InvocationBinding、WorkloadPeer、DirectWorkloadCaller）将请求绑定、mTLS 对端身份与调用链上下文分离建模，且明确标注 receiver-only 语义。
