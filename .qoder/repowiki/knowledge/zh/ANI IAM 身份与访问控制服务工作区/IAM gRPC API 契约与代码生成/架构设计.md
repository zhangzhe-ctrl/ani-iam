模块以 `api/go.mod` 为独立 Go module（github.com/zhangzhe-ctrl/ani-iam/api），仅依赖 grpc/protobuf 标准库，不含任何业务逻辑或存储依赖。

- 契约层：所有 `.proto` 文件位于 `iam/v1/`，统一声明 `package iam.v1` 和 `go_package = github.com/zhangzhe-ctrl/ani-iam/api/iam/v1;iamv1`，通过 `buf.yaml` 管理版本并依赖 `buf.build/googleapis/googleapis`。
- 共享类型集中在 `contract.proto`（Audience、PrincipalType、Boundary、BearerCredential、SessionSummary、IAMErrorReason 等枚举与消息）以及 `workload.proto`（InvocationBinding、WorkloadPeer、DirectWorkloadCaller 等工作负载绑定模型），被各服务 proto 引用。
- 服务契约按职责拆分：`authentication_service.proto` 暴露 AuthenticationService（密码/OIDC 登录、会话管理、邀请、工作负载令牌签发等）；`authorization_service.proto` 暴露 AuthorizationService；`iam_admin_service.proto` 暴露 IAM 管理服务；每个服务均配套 `_grpc.pb.go` 生成的 gRPC stub。
- 代码生成由 `buf.gen.yaml` 驱动，使用本地 `protoc-gen-go` 与 `protoc-gen-go-grpc`，启用 `paths=source_relative` 并将 gRPC 插件设为 `require_unimplemented_servers=true`，确保生成文件不可手动编辑。
- 依赖方向单向：服务 proto → contract/workload 共享类型 → googleapis 标准类型；Go 调用方仅依赖生成的 `*.pb.go` 与 `*_grpc.pb.go`，不反向引用实现。
