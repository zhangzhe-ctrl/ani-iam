- 配置统一以 JSON 结构体字段加 json tag 声明，并通过 `readJSON` 配合 `LimitReader(1<<20)` 与 `DisallowUnknownFields` 严格解析。
- 对外暴露的目标通过 `grpcworkload.Target` 注册，并使用 `Describe` 闭包将 DTO 映射为包含 TenantID/SubjectID/ResourceID/Mode/SourceOperation 的 `RequestScope`。
- 资源所有权校验以本地 `inventory` 切片 + `check(ctx, ResourceBoundary)` 方法形式实现，由 caller 的 `AuthorizationRequest.CheckResource` 与 receiver 的业务逻辑共同复用。
- 敏感文件（credential、request、TLS 私钥）仅在运行时按路径读取，绝不作为命令行参数或输出打印，并对权限位与大小做前置校验。
- 错误统一通过 `status.Error(codes.Unauthenticated|PermissionDenied, ...)` 返回，以便 gRPC 客户端直接识别认证/鉴权失败。
