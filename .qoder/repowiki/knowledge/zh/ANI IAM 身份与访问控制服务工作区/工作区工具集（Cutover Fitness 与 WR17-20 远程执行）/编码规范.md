- CLI 统一通过 `argparse` 子命令组织功能（如 `render`/`validate`、`serve`/`storage`/`check`/`http-smoke`），并以 `sys.exit(main())` 或 `raise SystemExit` 返回状态码。
- 远程执行前对输入源进行严格断言：校验 git HEAD/tree、逐文件 sha256/mode、限制新增未跟踪文件仅允许 scope 白名单内路径。
- 敏感数据写入时采用临时文件 + `os.chmod(0o600)` + `replace` 原子落盘，避免中间态泄露。
- 远端命令以 nohup 后台方式启动，通过 PID/日志/退出码三件套记录生命周期，禁止自动重试或重新分发。
- 生成产物通过二次重放（re-generate）并与首次输出逐文件比对，确保生成过程幂等可重复。
- 安全策略集中声明为常量集合（如 `ALLOWED_NAMESPACES`、`FORBIDDEN_EVIDENCE_KEYS`、`HEX40`/`DIGEST_IMAGE` 正则），由校验函数统一消费。
