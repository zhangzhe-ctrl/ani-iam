- 契约测试将期望的服务/方法清单与消息字段以 map/slice 常量声明在测试文件中，再通过 `assertServiceInventory` / `assertMessageFields` 统一比对，新增 API 需同步更新这些白名单。
- 对外部依赖（protobuf descriptor、fixture JSON、toolchain 版本、仓库 commit）均以 SHA256 形式固化在 `contract_pins.json` 或硬编码断言中，任何漂移都会导致测试失败。
- 集成测试统一通过 `wr20Environment` 或 `newPostgresEnvironment` 等工厂函数搭建隔离资源，并使用 `t.Cleanup` 注册容器/连接释放，避免测试间状态泄漏。
- 需要模拟外部依赖时采用接口+实现注入模式（如 `allowingIntegrationLoginThrottle`、`recordingAccessTokenIssuer`、`fixedClock`），而非全局变量或 mock 框架。
- 全链路测试通过 `recordReference` 将关键阶段（Dex 启动、Bootstrap、登录、请求）以 JSONL 行追加到 `run/private/` 下，便于事后回放与审计。
- 所有需要外部服务的测试均使用 `//go:build integration` 构建标签隔离，普通 `go test` 仅运行无外部依赖的轻量测试。
